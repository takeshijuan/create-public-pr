# Security policy

## Reporting a vulnerability

Use the repository's private security-advisory feature. Do not open a public issue for a vulnerability that could expose sensitive data or enable a bypass.

Include the affected version, a minimal reproduction using harmless placeholder data, impact, and a suggested remediation. Do not include real credentials, private links, personal addresses, internal hostnames, or proprietary files.

Maintainers will acknowledge a complete report, assess severity, coordinate a fix, and publish remediation details when disclosure is safe.
